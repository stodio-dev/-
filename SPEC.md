# CL v0.2 – Concept Language

A compact, domain-neutral language for machine-to-machine (and model-to-model) technical messages.
Goals: fewer tokens, no drift, no concept confusion, no translation through natural language.
Vocabulary: `lexicon.json`. For sending to a model use `lexicon.txt`: the same vocabulary plus a five-line grammar summary,
generated by `cl.py lexicon`; it is meant to be the only file a model needs. This file is the full, normative spec.

## Principles
1. **Concepts, not words.** Every code maps to one concept in the lexicon. No synonyms, no polysemy.
2. **Every concept has a contrast** (`not`): the nearest concept it must not be confused with.
3. **Epistemic status is grammar.** Every statement has a mode; each mode has required fields. Missing them makes the statement *invalid*.
4. **No paraphrase.** Free text only as `q="..."`, always a verbatim quotation.
5. **Cheap tokens.** Short ASCII codes. Emoji/symbols are a display layer only.
6. **Say a value once.** Defaults are omitted; repeated values go into `#` headers; times are offsets from a base.

## Grammar
```
message   := (header | statement)*
header    := '#' field+
statement := ['@'N] MODE TERM ['!']REL TERM field*
TERM      := ['!'] [QUANT '.'] CONCEPT [':' instance]  |  ['!'] '@'N
field     := key '=' value          # conf src t t0 ctx scope dur unit q
```
- **Headers** set defaults for every following statement until changed; a field written on a statement overrides the header.
- **Time:** `t` is unix seconds, or `+N` meaning `t0+N`. `#t0=...` (header only) sets the base. `t0` is not part of any statement.
- **Context:** `ctx=d01` says which incident/document/thread a statement belongs to. Usually set in a header.
- **References:** `@N` labels a statement; later statements may use it as a term. Ids are unique within the whole message, across contexts.
- **Negation:** `!term` negates a term; `!rel` negates the relation (`inf @1 !cause @2` = A did not produce B).
- `concept:instance` names a specific thing (`sys:srv1`, `val:92`). An instance with whitespace or quotes is shell-quoted.
- `QUANT.` is one of `all some one none many`. `scope` defaults to `all`.
- Numbers (`conf`, `dur`) are exact and finite.

## Modes (required fields in braces; definitions in the lexicon)
`obs {src t}` observed · `inf {conf src t}` inferred · `est {conf src t}` approximation of a present/past value ·
`pred {conf src t dur}` forecast · `unk {src t}` explicitly unknown · `req {src t}` request · `cmd {src t}` instruction ·
`ack {src t}` receipt of `@N` confirmed, nothing more; the subject must be that `@N` (form: `ack @N has recv`).

**`dur`** is in seconds and refers to the interval `[t, t+dur]`: for `pred` the claim holds *at some point* within it; for every other mode, *throughout* it.

## Validation (E_* codes)
| Code | Meaning |
|---|---|
| E_SYNTAX | wrong shape, subject/object missing, `ack` subject not an `@N` |
| E_MODE / E_REL / E_CONCEPT / E_QUANT | unknown code |
| E_FIELD / E_VALUE | unknown, duplicate or misplaced field (`t0` outside a header); bad value |
| E_MISSING | a required field is absent; relative `t=+N` without `t0` |
| E_REF | `@N` unknown, later, or duplicated |
| WARN | `obs` with `cause/enable/block/need` (causation is rarely observed; use `inf`) |

## Example
```
#ctx=inc7 src=mon t0=1730415600
@1 obs sys:srv1 has fail t=+0
@2 inf res:mem has full conf=.95 t=+40
inf @2 cause @1 conf=.9 t=+40
inf res:cpu !cause @1 conf=.8 t=+40
pred res:disk has full conf=.6 dur=3600 t=+60 src=planner
```
= "In incident inc7 the monitor observed srv1 failing; it infers (95%) that memory was full, that this caused the failure (90%),
and that the CPU did not cause it (80%). The planner forecasts (60%) that the disk will be full within an hour."

## Compatibility with v0.1
Every valid v0.1 message is valid v0.2 with the same meaning, except messages that use the removed `modifiers` codes
(`not more less max min cond`, never given a grammatical role) or an `ack` whose subject is not an `@N`.
All 12 experiment scenarios written in v0.1 parse unchanged. v0.1 is preserved at commit `1b3cfbd`.

## Known limits
- Token savings over dense English are small: 8–9% (o200k), plus a one-time cost for this file and the lexicon. See `docs/extended/token-measurement.md`.
- Models write CL by tendency, not by the grammar; a validator is needed wherever correctness matters.
- No ranges, sets or nested conditions. No domain vocabularies (deliberately, until a measured need).
